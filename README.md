# Инженерия ИИ-агентов — сайт курса

Открыть: **https://den271.github.io/ai-agent-course/**

Интерактивный учебный курс из 22 модулей: от agent loop и инструментов до MCP, A2A, безопасности, оценки, капстоуна и токеномики — агента-помощника, который обслуживает сам курс.

## Что внутри страницы

- **22 модуля** с планом практики и проверочным вопросом;
- **просмотрщик** Markdown и Python с подсветкой;
- **локальный тьютор** — поиск по материалам курса, без обращения в интернет;
- **самопроверка** с пояснениями к ответам;
- **прогресс** «изучено» в `localStorage` браузера;
- **прямые ссылки** на модуль и открытый документ: `#m7`, `#m2,modules%2F02_agent_loops.md`.

## Конспект модулей 1–7

- Интерактивная схема: [konspekt_moduli_01_07.html](https://den271.github.io/ai-agent-course/konspekt_moduli_01_07.html)
- Текст конспекта: [открыть в просмотрщике](https://den271.github.io/ai-agent-course/#konspekt) · [исходный Markdown](https://den271.github.io/ai-agent-course/konspekt_moduli_01_07.md)

На главной странице курса эти ссылки стоят в шапке.

## Как это устроено

`index.html` — единый файл: лекции, примеры и панель помощника вшиты внутрь, внешних зависимостей нет. Страница работает и с GitHub Pages, и локально двойным щелчком по файлу, в том числе без интернета.

Файл собран в продакшн-виде: HTML, CSS и JS минифицированы, комментарии и лишние пробелы удалены, лицензионный комментарий сохранён. GitHub Pages дополнительно отдаёт страницу с gzip.

Рядом лежат конспект и интерактивная схема модулей 1–7 — отдельные файлы для быстрого повторения.

Если рядом с сайтом поднять сервис помощника (`http://127.0.0.1:8000`), панель чата, «Мой путь» и «Экзамен» подключаются к нему автоматически. Без сервиса она скрыта и остаются офлайн-тьютор, просмотрщик и самопроверка.

Код курса, примеры и тесты в этот репозиторий не входят — здесь только опубликованная страница и конспект 1–7.
